# 🦋 Butterfly Curve Animation

A Python visualization project that animates the famous Butterfly Curve using mathematical equations, NumPy, and Matplotlib. The animation gradually draws the curve in real time, creating a smooth and visually appealing mathematical artwork.

---

## 📖 Overview

This project demonstrates how mathematical equations can be transformed into beautiful visual animations using Python. The Butterfly Curve is generated from its parametric equation with NumPy and animated using Matplotlib's `FuncAnimation`.

As the animation progresses, the butterfly is drawn point by point, showcasing the power of Python for mathematical visualization, scientific computing, and computer graphics.

The project is an excellent introduction to data visualization, plotting mathematical functions, animation techniques, and numerical computing in Python.

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/tejass-raj/Butterfly-curve-python.git
```

2. Navigate to the project folder

```bash
cd Butterfly-Curve-Animation
```

3. Install the required libraries

```bash
pip install numpy matplotlib
```

4. Run the program

```bash
python main.py
```
